# Task 1 - Data Cleaning & Preprocessing

## Objective
The objective of this task is to clean and prepare raw data for Machine Learning.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Titanic dataset was used for this task.

## Steps Performed

1. Imported and explored the dataset.
2. Checked for missing values and data types.
3. Handled missing values using median and mode.
4. Converted categorical features into numerical values using Label Encoding.
5. Standardized numerical features using StandardScaler.
6. Visualized potential outliers using boxplots.
7. Detected and removed potential outliers using the IQR method.
8. Saved the cleaned dataset as `cleaned_titanic_dataset.csv`.

## Files Included

- `Titanic.ipynb` - Complete Google Colab notebook
- `titanic_task1_dataset.csv` - Original dataset
- `cleaned_titanic_dataset.csv` - Cleaned and preprocessed dataset
- `boxplot.png` - Outlier visualization

## Conclusion

The raw Titanic dataset was cleaned and preprocessed successfully for further Machine Learning tasks.
